# Kitchen Chaos

## 1. 프로젝트 소개

오버쿡 스타일의 모바일 요리 액션 게임 포트폴리오 프로젝트입니다.
제한 시간 안에 주문을 확인하고 재료 가공 → 조리 → 플레이팅 → 주문 제출을 수행하는 게임입니다. 

> 상업적 목적이 아닌 개인 포트폴리오 프로젝트입니다. CodeMonkey의 Kitchen Chaos 리소스와 오버쿡2 리소스를 참고했으며, 클라이언트 구조는 프로젝트 목적에 맞게 재구성하여 구현했습니다.
>
> Reference: [CodeMonkey Kitchen Chaos](https://unitycodemonkey.com/kitchenchaoscourse.php)

## 3. 사용 기술

| 기술 | 사용 목적 |
| --- | --- |
| URP | 3D 게임 화면 렌더링 |
| UniTask | 리소스 로딩과 게임 초기화의 비동기 순서 제어 |
| Addressables | 스테이지별 리소스 로딩 및 해제 |
| Input System · UGUI | 키보드 및 모바일 터치 입력, 게임 UI 구성 |
| ExcelDataReader | Excel 기반 콘텐츠 데이터 변환 및 런타임 데이터 연동 |
| `ObjectPool<T>` | 재료 오브젝트 재사용 |
| Unity Editor 확장 | 주방 맵 제작 및 배치 검증 도구 구현 |

## 4. 구현 기능

* 요리 액션
  * 재료 획득, 손질, 조리, 플레이팅 및 완성된 음식 제출
  * 재료의 가공 상태와 조합에 따른 레시피 판정
  * 플레이어·조리대·도구 간 재료 및 접시 보유·이동 규칙 관리
  * 재료별 손질, 굽기, 끓이기 진행과 과조리·탄 상태 처리

* 주문 및 점수 관리
  * 주문 생성, 제한 시간 및 만료 처리
  * 완성된 메뉴와 대기 주문을 비교해 성공·실패 판정
  * 주문 제출 결과에 따른 점수와 게임 결과 UI 표시

* 모바일 터치 조작
  * 터치 위치 기반 이동과 카운터 상호작용
  * 그리드 기반 A* 경로 탐색
  * 선택한 카운터의 가장 가까운 접근 위치까지 자동 이동

* 게임 상태 관리
  * `KitchenGameContext` 중심의 모듈 생명주기와 의존성 관리
  * 게임 시작, 일시정지, 종료 및 재시작 흐름 처리
  * 맵 범위 안에서 플레이어를 부드럽게 따라가는 카메라 제어

* 데이터 기반 콘텐츠
  * Excel 기반 재료, 레시피, 스테이지 데이터 관리
  * 스테이지 설정에 따른 콘텐츠 구성과 Addressables 리소스 사전 로딩

* 주방 MapEditor
  * 그리드 기반 주방 오브젝트 배치
  * 레시피 기준 필수 설비와 맵 구성 검증
  * 검증 완료 후 스테이지 씬 생성

* 오브젝트 풀링
  * 재료 오브젝트를 재사용하여 반복 생성과 제거 비용 절감
  * 재료 Prefab 경로별 Pool 분리 관리
